OOGAM 디자인 검수

공식 홈페이지와 사내 워크스페이스의 현재 화면을 모았습니다. 맨 위의 결정 항목부터 보시고, 아래 화면을 눌러 원본 크기로 확인하세요.

18 화면46 스크린샷데스크톱 1440px · 모바일 390px구현 완료 8 · 부분 구현 5 · 기능 완료 · 콘텐츠 필요 5
모든 데이터는 가상입니다. "샘플" · "데모" · "가상"이 붙은 브랜드 · 프로젝트 · 직원 · 거래는 검수용입니다. 실제 브랜드 후보는 법인 관계 확인 전이라 넣지 않았습니다. "CMS에서 작성하세요"로 보이는 문구는 실제 현재 상태입니다 (공개 문구 미입력). 현재 프로덕션 빌드와 실제 서체(Pretendard)로 캡처했습니다.

대표 결정이 필요한 항목

번호는 처리 순서입니다. 1~3번은 공개 사이트 오픈 전에 필요합니다.

  1. 공개 사이트 문구 확정높음

    회사 소개·사업 영역·채용 안내·메인 소개 문단에 "CMS에서 작성하세요" 안내문이 공개 화면에 보입니다. 운영 전 실제 문구가 필요합니다. 담당자가 관리자 CMS에서 바로 입력할 수 있습니다.

  2. 브랜드 공개 범위와 자료높음

    듣다·Louver·247Streams·콘텐츠 제작·교육의 법인 관계를 확인한 뒤 공개 여부를 정해 주세요. 공개할 브랜드는 로고·대표 이미지·소개 문구가 필요합니다.

  3. 비주얼 방향: 사진 중심 vs 타이포 중심높음

    현재는 이미지 없이 타이포그래피만으로 구성되어 포트폴리오·사업 영역이 비어 보입니다. 프로젝트 사진·영상 썸네일을 준비할지, 이미지 없는 타이포 중심 디자인으로 다듬을지 정해 주세요.

  4. 푸터 회사 정보중간

    상호·대표자·사업자등록번호·주소·대표 연락처 표기 여부와 내용을 정해 주세요. 현재 푸터에는 메뉴와 문의 링크만 있습니다.

  5. 메뉴·섹션 언어 정책중간

    공개 메뉴와 섹션 제목을 영문으로 유지할지, 국문 병기할지 정해 주세요. 현재 영문과 국문이 섞여 있습니다.

  6. 관리자 상태 색상중간

    업무 상태 배지에 색(파랑·노랑·초록)을 쓸지, 흑백 톤 + 아이콘으로 통일할지 정해 주세요. 색은 상태 파악이 빠르고, 흑백은 브랜드 일관성이 높습니다.

  7. 관리자 메뉴 그룹화낮음

    14개 메뉴를 업무(내 업무·프로젝트·문서·데이터베이스·캘린더) / 경영(전자결재·재무) / 조직(직원·부서·공지·파일) / 관리(CMS·설정)로 묶을지 정해 주세요.

  8. Hero 대형 "OOGAM" 워드마크낮음

    메인 첫 화면에 헤드라인과 대형 워드마크가 함께 있습니다. 강한 브랜드 인상을 유지할지, 헤드라인만 남겨 간결하게 할지 정해 주세요.

결정 없이 다음 개발에서 바로 고칠 항목

  • 한글 라벨의 과도한 자간 제거
  • 업무·직원 상세 패널의 배경 처리 통일
  • 날짜 입력을 한국식(YYYY. MM. DD.) 표시로 통일
  • 모바일 에디터 툴바를 한 줄 스크롤 또는 "더보기"로 정리, 툴바 버튼에 이름 표시(툴팁)
  • 전자결재 상세를 열 때 해당 문서가 있는 탭으로 자동 전환
  • 파트너십 CTA 모서리를 다른 요소와 같은 직각으로 통일
  • 대시보드 지표 카드 수를 그리드에 맞게 조정 (모바일 2열 짝수)
  • 칸반 열마다 업무 추가 버튼, 키보드 이동 지원

디자인 시스템 검토

타이포그래피, 여백, 색상, 메뉴 구성, 정보 위계, 반응형 동작을 화면 전체에서 평가했습니다.

타이포그래피

양호

Pretendard 단일 서체로 국문·영문이 일관됩니다. 공개 사이트는 초대형 디스플레이(Hero 최대 156px)와 작은 영문 라벨의 대비가 강해 프리미엄 미디어 회사다운 인상을 줍니다. 관리자는 13~15px 본문으로 정보 밀도가 적절합니다.

  • 한글 라벨에도 넓은 자간이 적용되어 "크 리 에 이 티 브"처럼 글자가 흩어져 보임 (브랜드 카드·채용 메타)
  • 섹션 제목이 영문(Selected Work, Latest)과 국문(OOGAM과 함께하는 브랜드)으로 섞여 있음 — 언어 정책 결정 필요

여백 · 그리드

보완 필요

12열 그리드와 넉넉한 섹션 여백이 일관됩니다. 관리자 화면은 카드·표 간격이 고르고 정렬이 정확합니다.

  • 콘텐츠가 없는 영역(사업 영역 카드 상단, 회사 소개)이 큰 빈 공간으로 남음
  • 모바일 홈이 약 7,500px로 김
  • 파트너십 CTA만 둥근 모서리이고 나머지는 직각이라 형태 언어가 섞임

색상

결정 필요

공개 사이트는 블랙 #0A0A0A · 화이트 · 회색만 사용하고 포인트 컬러(오렌지)는 긴급 표시 등에 최소 사용해 방향과 일치합니다. 재무 차트도 흑백 톤입니다.

  • 관리자 상태 배지(진행 중=파랑, 검토=노랑, 완료=초록)와 개발 상태 안내(노랑)가 흑백 기조에서 벗어남 — 기능적 색으로 유지할지 결정 필요
  • 음수 금액은 빨강 표시 (유지 권장)

메뉴 구성

결정 필요

공개 사이트는 영문 7개 메뉴(About · Business · Brands · Portfolio · News · Careers · Contact)로 간결합니다. 관리자는 14개 메뉴가 한 줄 목록이며 권한에 따라 자동으로 숨겨집니다.

  • 관리자 메뉴 14개가 묶음 없이 나열 — "업무 / 경영 / 조직 / 관리" 그룹화 제안
  • 공개 메뉴 언어(영문 유지 vs 국문 병기) 결정 필요

정보 위계

양호

대시보드 → 목록 → 상세 패널 흐름이 일관되고, 핵심 수치를 먼저 보여줍니다. 재무 대시보드는 지표 → 추이 → 구분별 → 미승인 순서가 명확합니다.

  • 전자결재 상세와 왼쪽 목록 탭이 어긋날 수 있음
  • 업무 패널(어둡게)과 직원 패널(흐리게)의 배경 처리가 다름
  • 편집기 툴바가 아이콘만 있어 기능 파악이 어려움

반응형

양호

데스크톱·태블릿·모바일에서 가로 스크롤 없이 동작하며, 관리자 사이드바는 모바일 드로어로 전환됩니다. 키보드 포커스·명도 대비 자동 점검(axe) 심각 문제는 0건입니다.

  • 모바일 에디터 툴바 3줄
  • 데이터베이스 보드는 넓은 화면에서도 가로 스크롤
  • 대시보드 지표 카드 5개가 모바일에서 마지막 1개만 남음

화면 갤러리

화면마다 구현 완료된 기능과 미완성·개선 항목을 나눴습니다. 이미지를 누르면 원본 크기로 스크롤하며 볼 수 있습니다.
